
# SMT Breakout Boards

Some small adapter boards to help with prototyping SMT packages on a breadboard.

## Design

Using KiCad version

1. Place connectors in schematic and connect wires
2. Assign footprint.
3. In PCB editor arrange. Set connectors on back side as needed.
4. Draw traces and edge cuts.

## Supported Packages

A list of packages can be found here: <https://en.wikipedia.org/wiki/List_of_electronic_component_packaging_types>

Currently supported breakout boards are in the `packages` directory here.
